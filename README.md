# Critter Clash 🐸

Turn-based garden tactics. Lead three critters against the bugs — move, use each
one's special power, and shove the rest into the pond. No timers, no reflexes:
take as long as you like on every move.

**Play it here: https://rvenning.github.io/critter-clash/**

## Features

- **20-level campaign** across a garden, with bosses at 7, 14 and 20.
- **Five critters**, each with one special power on a cooldown — Hop the frog
  leaps over ponds and yanks bugs closer, Digger the mole smashes rock, Zip the
  bird blows bugs backwards off a ledge, Prickle the hedgehog rolls straight
  through a line of them, Buzz the bee heals. Prickle joins after 8 levels and
  Buzz after 14; pick your three (four for the finale) before each battle.
- **Terrain is the game.** Bugs can't swim, so a well-aimed gust is worth more
  than three hits. Bushes give armour, thorns bite, rocks block the way until
  Digger flattens them.
- **Four kinds of level** — beat every bug, reach the berry, collect all three,
  or hold out for six turns without losing anybody.
- **Two-player hot-seat**: one iPad, two players, three symmetric gardens and an
  optional health handicap so a four-year-old can beat an eight-year-old.
- **Stars** for winning inside par with the whole team standing, a family
  leaderboard, and progress that follows you between devices.

## How to play

Tap a critter, tap a green dot to walk there, then tap a bug to attack — or hit
the purple power button to aim its special. **Undo** takes a move back until you
attack, **Wait** finishes a critter's go, **End Turn** hands over to the bugs.

## Built on gamekit

Profiles + PINs, family sync, sound, screens and the install prompt all come
from [gamekit](https://github.com/rvenning/gamekit), vendored into `lib/`.
Re-vendor after a kit change:

```bash
node "../gamekit/tools/sync-to-game.js" "../critter-clash"
```

## Layout

| Path | What's in it |
|---|---|
| `js/tiles.js` `critters.js` `enemies.js` `levels.js` | Data registries — a new critter, bug or level is one entry |
| `js/rules.js` | Movement, damage, pushing, powers. Pure functions over the match state |
| `js/ai.js` | One utility scorer, used by the bugs and by the test bot |
| `js/game.js` | Turn engine. No DOM, no canvas, no audio |
| `js/render.js` | Canvas, input, animation, and the pacing of the bugs' turn |
| `js/main.js` | Screens, level map, team picker, duel setup, results |
| `tests/` | Level linter, headless balance bot, save-merge tests |

The engine is deliberately DOM-free and has no randomness anywhere, so
`tests/bot.test.js` can play all 20 levels headlessly and deterministically.

## PWA

`sw.js` (cache `critter-clash-vN` — **bump it whenever a shell file changes**),
`manifest.json`, and `icons/` generated by `node tools/make-icons.js`.

## Local development

```bash
npx http-server . -p 8106 -c-1
```

Then open http://localhost:8106. Add `?debug=1` for the dev panel (jump to any
level, force a win, hurt the team — saving is disabled while it's on).

## Tests

```bash
node --test
```

`tests/levels.test.js` lints every map (row widths, unknown tiles, units inside
rocks, and a flood fill proving a walking critter can reach the objective).
`tests/bot.test.js` plays the campaign with the AI driving both sides and
asserts every level is winnable, none is trivial, and no level can be won by
never touching the screen. `node tests/bot.test.js --report` prints the
per-level turn counts.

## Storage

`cc_*` in localStorage, Firestore collection `critterclash` in the shared
family project. The Firebase config in `js/firebase-config.js` is a client key,
not a secret — it's restricted to the Cloud Firestore API.
